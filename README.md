Sistema de Turnos
Proyecto inicial de una página web desarrollada únicamente con HTML, cuyo objetivo es presentar la estructura básica de un sistema de gestión de turnos.

📋 Descripción
La página funciona como una presentación inicial de un sistema de turnos. Incluye información sobre las opciones disponibles y los horarios de atención.

Este proyecto está pensado como una primera práctica de estructura y organización de una página HTML, sin utilizar JavaScript ni otros lenguajes.

🛠️ Tecnologías utilizadas
HTML5

No se utiliza JavaScript.

No se utilizan frameworks ni librerías externas.

📁 Estructura del proyecto
sistema-de-turnos/
│
├── index.html
└── README.md

index.html
Contiene toda la estructura de la página:

header: encabezado.

h1: título principal.

main: contenido principal.

section: secciones de información.

h2: títulos secundarios.

p: párrafos descriptivos.

ul: lista de opciones.

li: elementos de la lista.

footer: pie de página.

HTML

🚀 Cómo ejecutar el proyecto
Descargar o clonar el proyecto.

Abrir la carpeta del proyecto.

Abrir el archivo index.html con cualquier navegador web.

La página se mostrará directamente en el navegador.

🎯 Objetivo del proyecto
El objetivo es practicar:

La estructura básica de HTML5.

El uso correcto de etiquetas semánticas.

La organización del contenido mediante secciones.

La creación de listas.

La utilización de títulos y párrafos.

La construcción de una página web sencilla y ordenada.
